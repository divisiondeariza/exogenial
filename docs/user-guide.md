# User Guide

## Cargar un archivo

1. Open the app.
2. Select an `.xlsx` or `.xls` file with the informacion exogena report.
3. Wait for the dashboard to render.

The file is read locally in the browser.

## Revisar el resumen

The top summary shows:

- Consultante name and identification.
- Report year.
- Report date and cutoff date.
- Total reported value.
- Number of third-party informants.
- Number of detailed records.

## Revisar topes

The threshold cards show the report values for:

- `Tope 1 - Ingresos`
- `Tope 2 - Patrimonio`
- `Tope 3 - Consumo TC`
- `Tope 4 - Movimiento`
- `Tope 5 - Compras`

These values help identify which parts of the declaration may need closer review.

## Buscar y filtrar

Use the search field to find records by NIT, informant name, detail, declaration use, or additional information.

Use the `Tope` filter to focus on a specific threshold category.

Use the sorting control to order by:

- Highest value.
- Informant name.
- Detail text.

## Ver detalles

Select `Ver` in any table row to open the detail panel. This is useful for long fields such as `Uso declaracion sugerida` and `Informacion adicional`.

## Exportar

Use `CSV` to export the currently filtered records.

## Limitations

The app helps review reported third-party information. It does not validate the tax return, replace DIAN systems, replace accounting records, or provide tax advice.
